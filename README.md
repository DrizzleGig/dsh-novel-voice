## 把你喜欢的小说，变成 AI 写作的风格。

喜欢某部小说的叙事方式，想让 AI 写出相近的故事氛围？或者已经有自己的原创作品，希望 AI 延续并发展其中的独特文风？

「创作风格」支持导入你喜欢的小说和自己的原创作品，从真实文本中提炼写作特点，建立专属风格档案。你可以融合不同作品的风格，也可以把自己的创作加入其中，逐步形成自己喜欢、独一无二的写作风格。

写作前，插件将风格整理成简短的写作提示；写作后，帮你发现套话、重复表达和偏离风格的句子，还能对指定片段进行定点改写。

喜欢什么样的小说，就从什么样的作品开始；想形成什么样的文风，就把它一点点变成自己的风格。

**默认关闭** · **不写正文** · **不打分** · **不训练模型**

**0.2.0 已发布（2026-11-21）**：排字房工作台（来源地图 / 只读对照镜 / 档案时间线 / 420px UI）。G1 与斗罗同人 12 章章节验收已过；G2 正式作者标注、G3 盲选、G4 真实模型 `fix:true` 仍待补，不宣称全部验收通过。

```text
导入作品 → 本地统计 → 建风格档案 → 写前编译简报 → 写 → 检查 → 定点改写 → 反馈记账
```

## 它怎么工作

- **读**：导入参考作品和你自己的原创作品；分章、统计、场景切分全在本地完成，不调用模型。
- **记**：把分散的写法整理成四层风格档案（L1 画像 / L2 表达 / L3 策略 / L4 场景），技法卡带原文证据。
- **写**：写前编译一份 ≤600 字的简报——3–5 条写法、≤8 条禁语、1 条锚点；有自己的作品时再附一段 ≤400 字的样段。
- **改**：写后把套话、否定-修正、段末升华、情绪直述定位到句子；只改命中窗口，五道校验，改完可回滚。

## 快速开始

不用改变原来的写作方式，也不用一直开着。

### 1. 安装

```bash
dsh plugin --profile web add dsh-novel-voice
```

或直接从 GitHub 安装：

```bash
dsh plugin --profile web add github:DrizzleGig/dsh-novel-voice
```

本地开发也可以把目录指给插件管理器；装好后重启或重新加载插件。

### 2. 开启

默认关闭。在 DSH 对话里输入：

```text
/voice on
```

右栏会出现「创作风格」，点开就是「风格工作室」。

### 3. 三步拿到第一份简报

1. **书架**：先把「来源」切到参考作品或我的旧稿，再点「选文件夹 / 选文件 / 输入路径」导入；导入后自动统计，显示「待统计」时点一下「统计」即可。
2. **风格**：点「用模板建档案」，得到一份 v1.1 的已确认档案；技法卡可以点开看原文证据。
3. **底部按钮**：生成文风简报，复制给模型或直接让它按简报写。

写完用 `voice_check` 定位问题；要改才用 `voice_polish fix:true`——它默认只报不改。

## 面板

侧栏入口叫「创作风格」，点进去叫「风格工作室」，0.2.0 重做为「排字房」：420px 单列、暖纸/墨字、衬线标题、细线；三个 tab + 五个 sheet。

- **书架**：容量、作品卡、来源类型、统计状态、证据条数；每本可「统计」「看证据」「移除」（移除会删本地副本，二次确认）。
- **档案**：风格卡（一句话 + 模式 + 统计）、**来源与证据**（按作品列证据条数，条形按证据条数而不是权重）、核心选择、模式权重、档案时间线、**对照镜**主入口。
- **学习**：候选技法（支持/反例，确认 / 忽略）、版本记录（只展示，回滚走 `voice_profile rollback`）、最近反馈。
- **Sheet**：简报（场景切换 + 预览 + 复制）、证据（每条规则/作品的原文与 hash）、时间线（版本与变更）、对照镜（粘贴文本 → 六项区间 + findings，无评分）、导入（参考/旧稿 + 文件夹/文件/路径）。

**参考作品影响哪些层？** 导入的参考作品会进入 L1 总则、L2 区间、L4 场景模式与锚点；L3 技法卡要么来自模板（标「模板」、没有原文证据），要么点「从作品提取」用模型提取（带引文，先落为候选，在「学习」里确认）。自己原创作品还会额外提供 ≤400 字的人名遮蔽样段。

检查与改写仍在对话里完成：面板不直接改稿。对照镜也不评分：只显示「命中 / 偏离 / 未覆盖 / 无法判断」，不设总分、百分比或排名。

## 七个工具

| 工具 | 作用 |
|---|---|
| `voice_import` | 导入 / 列出 / 移除作品，分章预览与手动修正 |
| `voice_learn` | `measure` 本地统计；`sample` 取样预览；`analyze` 模型提取技法；`commit` 写进档案 |
| `voice_profile` | 档案：list / show / create / confirm / update / weights / rollback / templates / apply / regenerate |
| `voice_brief` | 编译当前场景的写前简报（≤600 字，附锚点与样段） |
| `voice_check` | `lint` 定位问题；`rank` 对 2–3 份候选指出谁更接近档案（不判好坏） |
| `voice_polish` | 定点改写：只改命中窗口，五道校验；默认只报不改 |
| `voice_feedback` | 反馈记账、聚合候选、确认 / 忽略、标黑短语 |

## 检查器与改写规则

能"判罪"的只有四类，外加两类硬伤：

| 类型 | 级别 |
|---|---|
| 套话密度（按段报） / 否定-修正句 / 段末升华 / 抽象情绪直述 | `warn` |
| 与书架作品 20 字连续重合 / 同人契约禁忌 | `block` |

句长、段长、对话比、抽象词密度、解释性连接词只做画像，与档案区间比对后给 `info`——**不是缺陷，只是"和你的档案不一样"**。

定点改写要过五道校验：

| # | 校验 | 不过怎么办 |
|---|---|---|
| V1 | 字数变化 ≤15% | 回退该窗 |
| V3 | 不新增数字 / 人名 / 引号内容 | 回退（编造比 AI 味更糟） |
| V2 | 窗口内原文保留度 ≥45% | 回退（不许整段重写） |
| V4 | 命中必须减少，且不引入新类型 | 重试一次，仍失败回退 |
| V5 | 不新增与参考作品的 20 字重合 | 回退 |

回退的窗口标 `needs-author`，原文不动。**宁可不改，不可改坏。**

## 设计原则

1. **证据先于结论**：技法卡的引文必须逐字回查，找不到就丢。
2. **统计不进简报**：模型数不准频率，简报只写可感知、作者说得清的事。
3. **定点改，不整章重写**：改哪里、为什么改、改没改坏，都要能核对。
4. **作者拥有最终决定权**：只给位置和理由，默认不改正文，不打分。
5. **反馈只记账**：同一条意见出现两次才进"待确认"，作者确认才升级。

## FAQ

### Q1：它和普通的"AI 文风模仿"有什么区别？

它不克隆某位作家、不训练模型、不给相似度评分。它把参考作品拆成可解释、可确认、可回滚的写作策略，并且只对命中句做最小改写。

### Q2：导入小说会消耗 Token 吗？

不会。导入、分章、统计、场景切分全在本地完成。只有两处会调用模型：`voice_learn analyze`（可选，先看 `sample` 预览）和 `voice_polish fix:true`。

### Q3：它会给我的小说打分吗？

不会。没有文笔分、风格分、AI 味分，也没有作家相似度和排行榜。检测结果只给位置、原句和理由。

### Q4：它会自动改我的正文吗？

不会。默认 `dryRun`，只有显式 `fix:true` 才改写；每个窗口都要过五道校验，不过就回退。

### Q5：点赞、点踩会让它自动学习吗？

不会自动改档案。反馈只落盘并聚合；同一 scope 出现两次才进"待确认"，你点确认才写进档案，而且有版本可回滚。

### Q6：目前有哪些限制？

- 召回 / 盲选 / 零编造的真实验收：G1（人工误报）与斗罗同人 12 章章节验收已过；**G2 正式作者标注、G3 盲选、G4 真实模型 `fix:true` 仍未完成**，不要对外宣称「全部验收通过」；
- 不做文笔评分、作家相似度、模型训练；对照镜不返回 score/total/percent；
- 面板不直接改稿，检查与改写走 `voice_check` / `voice_polish`；
- 浏览器上传单文件 ≤6 MB，更大的整本用「选文件夹」；
- 同人契约读 `.dsh-novel-fanfic/<project>/project.json`（兼容旧 `book.json`），但只取禁忌数组，不是完整契约编译器。

## 测试与验证

- `npm test`：**63/63** 通过；`npm run check` 检查 7 工具 / 20 remote（含 `mirror` / `chapterText` / `verifyEvidence`）、命名与契约同步。
- 真实语料（《斗罗大陆》原著 24 章 / 96,463 字）：人工正文误报 **0.10 处/千字**。
- 正控（故意写满 AI 味）：11.7 处/千字；12 章 AI 同人初稿只有 0.04 处/千字——不是检测器失灵，而是这批稿子的 AI 感在节奏层（句长 15 vs 原著 31、段长 25 vs 66），已由 L2 节奏规则覆盖。
